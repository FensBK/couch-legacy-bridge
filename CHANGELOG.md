# Changelog

## 0.7.5
- Brazilian Portuguese translation for Couchcraft's screens.
- Guests can open the player list (SELECT) and chat again; Host Options stay player 1's only.
- "Vertical Split Screen" now applies immediately.
- No name tag on GUI player figures (inventory, paper doll).
- Fixed a startup crash from an ambiguous mixin target (0.7.1).

## 0.7.0
- "Vertical Split Screen" option in Game Options and "HUD Size (Split Screen)" in User Interface.

## 0.6.x
- Guest menus limited like on console (no settings, mods, saving, host options).
- Fix: crash when a guest joins with a world border on screen.
- Fix: guest couldn't double-tap sprint while player 1 had a menu open.
- Fix: guest pointer stayed on screen after closing the inventory.

## 0.5.0
- Console-style join: START, then START again.
- Removed the "START to join · BACK to play as P1" corner hint; BACK on a free pad no longer takes over player 1.
- Per-player paper doll; guest pointer visible in inventories.
- Couchcraft settings reachable from Legacy4J's Mods menu.

## 0.4.0
- Legacy4J drives every guest's controller (navigation, layout, icons, remapping).
- "Leave Session" dialog for guests.

## 0.3.x and earlier
- Legacy4J owns player 1's controller; Legacy HUD for guests; per-profile skins and favorites; per-player control tooltips and HUD timers; crash fix while a guest picks a profile.
